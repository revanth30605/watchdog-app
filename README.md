#  WatchDog — Intelligent Change Detection

WatchDog is a modern web-based application that helps users monitor websites and detect changes automatically.
It provides real-time alerts, analytics, and AI-powered summaries for better tracking.

---

## 🚀 Features

* 🔍 **DOM Change Detection** – Detects changes in website content and structure
* 💰 **Price Tracking** – Monitor price changes on e-commerce sites
* 🔔 **Smart Alerts** – Get notifications for important updates
* 🤖 **AI Summaries** – Understand changes with simple explanations
* 📊 **Dashboard Analytics** – Visual insights and reports
* 🛡️ **Anomaly Detection** – Identify unusual changes

## ▶️ How to Run the Project

1. Download or clone the repository:

   ```bash
   git clone https://github.com/your-username/watchdog-app.git
   ```

2. Open the folder in **VS Code**

3. Open `watchdog-app.html`

4. Right-click → **Open with Live Server**
   *(or double-click to open in browser)*
